SMS Text Classifier:
A machine learning project that classifies SMS messages as Spam or Ham (Not Spam) using Natural Language Processing and TensorFlow.

Project Overview:
The SMS Text Classifier is a machine learning model that analyzes the content of an SMS message and predicts whether it is spam or a normal message.

This project was completed as part of the freeCodeCamp Machine Learning curriculum.

Technologies Used

Python

TensorFlow

Natural Language Processing (NLP)

Machine Learning

NumPy

Pandas

How It Works

SMS messages are loaded from the dataset.

The text data is preprocessed.

The messages are converted into a format that can be processed by the neural network.

The model is trained using the training data.

The trained model predicts whether new messages are Spam or Ham.

💡 Example

Input

Congratulations! You have won a free prize. Call now!

Prediction

Spam

Another Example

Hey, are you coming to college today?

Prediction

Ham

📊 Model Performance

The trained model achieved approximately 97% accuracy on the test data.
